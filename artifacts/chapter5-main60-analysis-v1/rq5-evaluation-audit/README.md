# RQ5 evaluation disagreement audit

This offline artifact supports Section 5.6.5. It freezes the full 900-answer score distribution, four transparent diagnostic tails, a manually reviewed cause code for every screened row, exact-input Judge consistency, and metric-direction checks for the principal architecture comparisons.

The diagnostic thresholds select cases for inspection; they are not definitions of evaluator error. Question, answer, evidence, prompt, and Judge-rationale text are intentionally excluded. Full Context has no retrieval Evidence Recall. No API or network call is made.
